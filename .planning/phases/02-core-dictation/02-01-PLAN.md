Create `VoiceType/Transcription/TranscriptionService.swift`:

`@MainActor final class TranscriptionService: ObservableObject` — thin wrapper around the cached WhisperKit pipe (held by `ModelDownloadManager`). Does NOT own pipe creation — delegates to ModelDownloadManager.

```swift
import WhisperKit

extension TranscriptionService {
    /// Transcribes a Float32 mono 16kHz audio array to text.
    /// - Parameter audioArray: Float32 PCM samples from AudioCaptureService RingBuffer.
    /// - Returns: Punctuated, filler-word-filtered text string.
    /// - Throws: `.modelNotDownloaded` if model isn't ready, `.audioTooShort` if <300ms.
    func transcribe(audioArray: [Float]) async throws -> String
}
```

Implementation details:
- Accepts `modelDownloadManager: ModelDownloadManager` in init (not owning pipe creation directly)
- Guard `modelDownloadManager.getPipe()` is non-nil → else throw `.modelNotDownloaded` (D-17)
- Guard `audioArray.count >= Int(AudioConstants.sampleRate * 0.3)` (300ms minimum per PITFALLS.md §2) → else throw `.audioTooShort`
- Run transcription in `Task.detached(priority: .userInitiated)` — Whisper inference is CPU/ANE-heavy, must NOT block main thread (PITFALLS.md §7, §12)
- `DecodingOptions`:
  - `task: .transcribe`
  - `detectLanguage: true` — (D-14: auto-detect Chinese/English)
  - `chunkingStrategy: .vad` — (D-05: WhisperKit built-in VAD, single dependency)
  - `skipSpecialTokens: true`
- Call `pipe.transcribe(audioArray: audioArray, decodeOptions: options)` — exact parameter labels per RESEARCH.md A1 (adapt to Xcode autocomplete if 0.18.0 labels differ)
- Join all segment texts: `results?.map(\.text).joined(separator: "") ?? ""`
- Post-process with filler word removal (delegate to the utility from Task 1, or inline if colocated)
- On success: return cleaned text. On failure: throw `.transcriptionFailed(underlying: error)`.
- Log transcription duration and character count via `Log.transcription.info`

**CRITICAL constraints:**
- `WhisperKit.transcribe(audioArray:decodeOptions:)` expects Float32 PCM at 16kHz mono — matches `AudioCaptureService` RingBuffer format EXACTLY (DICT-03, Phase 1 compatibility)
- Do NOT call `modelDownloadManager.initialize()` from this class — ModelDownloadManager initialization is orchestrated by AppCoordinator (Plan 03)
- `chunkingStrategy: .vad` enables WhisperKit's built-in silero-vad segmentation — no external VAD dependency (D-05). The VAD handles silence/speech boundaries, Whisper transcribes each segment.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local FS → Process | Whisper model files (~626MB) loaded from disk via Core ML / ANE — large binary blobs with no integrity verification beyond HuggingFace source trust |
| RingBuffer → WhisperKit | Float32 audio samples cross from audio capture (Phase 1) into Core ML inference — in-process but across subsystem boundary |
| WhisperKit → Memory | Transcribed text held in memory before TextIO insertion — sensitive if user dictated private content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Information Disclosure | TranscriptionService | medium | mitigate | Audio processed entirely in-memory (RingBuffer → TranscriptionService → text); no audio written to disk. Audio buffer cleared after transcription (RingBuffer.reset() in AudioCaptureService.stop()). |
| T-02-02 | Denial of Service | ModelDownloadManager | low | accept | Large model download (~626MB) could fill disk on constrained systems. Accept — user explicitly chose large-v3 model; tiny fallback exists (D-01). First-launch download is a known, documented prerequisite. |
| T-02-03 | Tampering | ModelDownloadManager | low | accept | Model files downloaded from HuggingFace CDN via HTTPS — integrity relies on WhisperKit's built-in verification. No local checksum validation added. Accept — HuggingFace is the official distribution channel; model tampering would require CDN compromise (high-effort, low-likelihood for an offline dictation tool). |
| T-02-04 | Elevation of Privilege | TranscriberService | low | accept | WhisperKit runs Core ML / ANE computations in-process with full app permissions. Accept — WhisperKit is a well-audited open-source framework (6.3k stars); risk of malicious model execution is theoretical for Core ML sandbox. |
| T-02-05 | Information Disclosure | Logging.swift | low | mitigate | Log.transcription logs character count and duration but never the transcribed text itself. Action explicitly instructs "Log transcription duration and character count" without logging raw text. |
</threat_model>
