# VoiceType

用语音来打字，说错了不用摸键盘——再按一下热键，说句人话就能改回来。

## 解决的问题

语音输入很方便，但语音识别经常出错。比如你想说"创建一个用户登录函数"，结果识别成了"窗间一个用户登录函数"。这时候你只能放下话筒，用键盘一个一个字改回去。

VoiceType 让你**继续说，不用碰键盘**。按一个纠错键，对着话筒说"把窗间改成创建"，AI 就会自动找到刚才那句错误文字，把它改对。

## 两种工作模式

### 1. 听写模式：语音转文字

按住一个热键（比如 Fn 键），开始说话，松开后你说的话就变成文字，出现在光标的位置。

> 适合：正常码字、写代码、写文档

### 2. 纠错模式：语音修错字

按下另一个热键（比如 Ctrl+Shift+C），说出你的纠错指令，AI 会分析你之前输入的错误文字，原地修正。

> 适合：听写结果不对、想改措辞、想换一种写法

纠错命令是**说人话，不用记指令**。比如：

- "把窗间改成创建"
- "第三个参数改成 userId，类型改成 string"
- "把这句话拆成两句，补上注释"
- "把这段代码的变量名全改成驼峰命名"

## 使用示例

假设你正在写代码，全程不用键盘：

```
[按住 Fn] def get user by email database email

编辑器出现：
    def get_user_by_email(database email)

[按下纠错键] 把参数改成 db_conn 和 email，加逗号和冒号

编辑器修正为：
    def get_user_by_email(db_conn, email):

[按住 Fn] sql等于select星号from users where email等于冒号email

编辑器出现：
    sql = select * from users where email = :email

[按下纠错键] 把sql=改成return f三个引号，下面补上db点execute sql

编辑器修正为：
    return f"""
        SELECT * FROM users WHERE email = :email
    """
    db.execute(sql)
```

写长文档也是同样流程——说错就按纠错键说句"把上一段改成……"。

## 怎么做到的

四个步骤，背后发生的事情：

1. **听到纠错指令**：你按下纠错键，系统开始录音，检测到你停顿下来就停止录音
2. **理解你说了什么**：通过语音识别引擎（Whisper）把你的纠错命令转成文字
3. **AI 分析并修正**：把你屏幕上光标附近的文字 + 你的纠错命令一起发给大模型，大模型找出需要修改的部分，生成修正后的文字
4. **原地替换**：用修正后的文字替换掉原来有错的那一段

## 通用性

不是某个编辑器专属的插件。只要你的应用里有文字输入框，VoiceType 就能用：

- 代码编辑器（VS Code、IntelliJ、Vim……）
- Office 办公软件（Word、WPS……）
- 聊天工具（微信、飞书、Slack……）
- 浏览器里任何输入框（写邮件、写文档、填表单……）

原理是通过操作系统级的辅助功能接口（无障碍 API）和模拟粘贴来读写文字，不依赖特定软件。

## 平台与选型

| 组件 | 做什么 | 怎么做 |
|---|---|---|
| 语音转文字 | 把你的录音变成文字 | Whisper 本地模型，离线可用 |
| 大模型 | 理解纠错意图、修正文字 | GPT-4o 或 Claude API |
| 语音检测 | 判断你什么时候说完了 | silero-vad，本地运行 |
| 热键监听 | 捕获全局按键 | 操作系统原生 API |
| 文字读写 | 从任意应用读文字、写文字 | 无障碍接口 + 剪贴板 |

首选 macOS 平台先做出来，后续扩展到 Windows。

## 不是什么

- 不是语音编程助手（不会帮你写代码，只是帮你改正打错的部分）
- 不是语音操控工具（不会帮你操作电脑，只负责文字输入和纠错）
- 不是语音笔记工具（工作在任何文字输入场景，不局限于特定应用）
