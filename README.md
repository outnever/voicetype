# VoiceType

用语音来打字，说错了不用摸键盘——再按一下热键，说句人话就能改回来。

## 解决的问题

语音输入很方便，但语音识别经常出错。比如你想说"创建一个用户登录函数"，结果识别成了"窗间一个用户登录函数"。这时候你只能放下话筒，用键盘一个一个字改回去。

VoiceType 让你**继续说，不用碰键盘**。长按热键，对着话筒说"把窗间改成创建"，AI 就会自动找到刚才那句错误文字，把它改对——**只改那一处，其他内容原样保留**。

## 工作方式

### 听写：用 macOS 系统自带的语音输入

- **双击 Fn** 触发系统听写（macOS 原生功能，识别质量最好）
- 说话 → 文字直接输入到光标位置

### 纠错：VoiceType 的 AI 修正

- **长按 Fn**（按住超过 0.5 秒）或 **⌥+回车**，说出纠错指令
- 松开后，AI 分析光标所在输入框的内容，执行你的指令
- 左下角半透明面板实时显示你的语音内容和修正结果

> 长按 Fn 与系统听写不冲突：短按/双击是系统听写，长按是 VoiceType 纠错。

## 支持的纠错指令

**说人话，不用记指令**。例如：

| 类型 | 示例指令 |
|------|---------|
| 改字/改词 | "把窗间改成创建"、"把这样全部改成那样" |
| 删内容 | "把刚才的那一句删掉"、"帮我删掉最后一行" |
| 清理全文 | "把当前文本中的所有乱码去掉"、"去掉所有的多余空行" |
| 新增内容 | "在光标处添加道德经的前五句"、"帮我写一段产品的介绍文案" |
| 组合指令 | "第三个参数改成 userId，类型改成 string" |

**同音字自动纠错**：语音识别可能把"块"识别成"快"——AI 会结合上下文推断你的真实意图，不会机械执行错字指令。

## 怎么做到的

1. **听到纠错指令**：长按热键开始录音，松开结束（Apple 语音识别，流式转文字）
2. **读取上下文**：通过 macOS 辅助功能（无障碍 API）读取光标所在输入框的全部内容（读取失败自动回退剪贴板方案）
3. **AI 分析**：上下文 + 纠错指令发给大模型，大模型返回结构化修改方案（局部片段 / 全文替换 / 光标处插入）
4. **执行**：只替换指定片段（局部修改）、整体替换（全文操作）、或在光标处插入（新增内容），其他内容不动

## 首次使用

### 方式一：安装 .app（推荐，无需命令行）

1. **macOS 14+，Apple Silicon（M1/M2/M3/M4）**，从 [GitHub Releases](https://github.com/outnever/voicetype/releases) 下载 `VoiceType.dmg`（或 zip）
2. 解压后**右键点击 VoiceType.app → 打开**（第一次需要右键打开绕过 Gatekeeper；如果仍提示无法验证开发者，运行 `xattr -cr /Applications/VoiceType.app`）
3. 拖入 /Applications
4. 菜单栏图标 → 偏好设置 → API 密钥，填入任一供应商的 Key（DeepSeek / OpenAI / OpenRouter / 自定义）
5. 授权：麦克风、辅助功能（勾选 VoiceType）、语音识别（首次纠错时弹出）

> Intel Mac 暂无预编译包：需要 Xcode 命令行工具后自行 `swift build`，请参考下方「构建与运行」。

### 方式二：源码运行（开发用）

1. **安装依赖**：需要 macOS 14+，构建需要 Xcode 命令行工具（`xcode-select --install`）
2. **配置 API Key**：菜单栏图标 → 偏好设置 → API 密钥，填入任一供应商的 Key（DeepSeek / OpenAI / OpenRouter / 自定义）
3. **授予权限**：首次使用时授权
   - 麦克风权限（听写/纠错录音）
   - 辅助功能权限（读取/写入任意应用的文字）——注意：用 `swift run` 运行时需给**终端**授予辅助功能权限
   - 语音识别权限（Apple 识别服务）
4. **启动**：`swift run`，菜单栏出现麦克风图标

> API Key 存储在 `~/Library/Application Support/VoiceType/api-keys.json`（明文，请勿分享该文件）。

## 构建与运行

```bash
# 构建
swift build

# 运行（需在图形界面环境，菜单栏应用）

```

## 技术栈

| 组件 | 选型 | 说明 |
|------|------|------|
| 语音识别（纠错指令） | Apple SFSpeechRecognizer | 云端免费，简体中文，流式识别 |
| 听写 | macOS 系统原生 | 双击 Fn，不占额外资源 |
| 大模型纠错 | DeepSeek / OpenAI / OpenRouter | OpenAI 兼容 API，可多供应商 |
| 热键监听 | CGEvent tap | Fn 长按（纠错）+ ⌥+回车（快速纠错） |
| 文字读写 | 辅助功能 API + 剪贴板回退 | 支持绝大多数应用 |
| 界面 | SwiftUI MenuBarExtra | 菜单栏应用 + 常驻状态面板 |

## 已知限制

- **需要网络**：纠错依赖大模型 API，Apple 语音识别也走云端
- **需要 API Key**：每个用户需在偏好设置里配置自己的大模型 Key（DeepSeek 等）
- **辅助功能依赖**：不支持无障碍 API 的应用（浏览器/Electron 自定义编辑器等）无法"精确替换"单个片段，但"新增内容"和听写仍可通过剪贴板回退正常工作
- **明文 API Key**：配置文件是明文，仅适合个人本机使用
- **Apple Silicon only**：预编译 .app 仅支持 arm64；Intel Mac 需自行构建
- **ad-hoc 签名**：未公证，首次打开需右键 → 打开（或 `xattr -cr`）
- 单次语音识别最长 1 分钟（对指令/听写足够）

## 通用性

不是某个编辑器专属的插件。只要应用里有文字输入框，VoiceType 就能用：

- 代码编辑器（VS Code、IntelliJ、Vim……）
- Office 办公软件（Word、WPS……）
- 聊天工具（微信、飞书、Slack……）
- 浏览器里任何输入框（写邮件、写文档、填表单……）

原理是通过操作系统级的辅助功能接口和模拟粘贴来读写文字，不依赖特定软件。

## 不是什么

- 不是语音编程助手（不会帮你写代码，只是帮你改正打错的部分）
- 不是语音操控工具（不会帮你操作电脑，只负责文字输入和纠错）
- 不是语音笔记工具（工作在任何文字输入场景，不局限于特定应用）
